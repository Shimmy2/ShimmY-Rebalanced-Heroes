## Rebalanced Heroes


## Main Features
Aimed to ballance starting specialties/ skills and remove useless or duplicate specialties. Added 3 new spell specialties and 1 new creture specialty. Ballanced Eagle Eye I and Medicine Wog options to better synergize with hero specialties.

## Description
- Removed Eagle Eye I option Wisdom requirement to be more of a might skill. Eagle Eye I specialists can learn level 5 spells after level 15.
- Medicine option now gives 5/10/15% health bonus instead of 1/2/3. Medicine specialists get a 5% per level bonus.
- Added new Lightning Bolt, Fire Shield and Sorrow spell specialties.
- Added new Air Elemental creature specialty.
- No more duplicate specialties from the same faction and no more Navigation specialty.
- All Tower might heroes start with Learning Secondary Skill instead of Mysticism/ Scholar.
- Most Eagle Eye specialties have been moved to might heroes or removed, to synergize with Eagle Eye I or II.
- Speed specialty now gets +1 speed and +1 extra speed for every 20 levels.
- Sanya now has Intelligence specialty.
- Thane now has Archery specialty.
- Serena now has Sorcery specialty.
- Daremyth now has Precision specialty.
- Pyre now has Armorer specialty.
- Gundula now has Archery specialty.
- Oris now has First Aid specialty.
- Bron now has Resistance specialty.
- Voy now has Speed specialty.
- Tiva now has Bless specialty.
- Pasis now has Offence specialty.
- Thunar now has Estates specialty.
- Ignissa now has First Aid specailty.
- Inteus now has Fireball specialty.
- Gelare now has Ice Bolt specialty.

## Installation
1. Download via Mod Browser or Extract the mod files to your Heroes III ERA/Mods/ installation directory
2. Enable the mod in the Mod Manager
3. Start a new game and have fun

## Compatibility
Compatible with all Wog options, Era scripts and JS-main module.

## Incompatibility
Incompatible with Advanced Clases Mod.
